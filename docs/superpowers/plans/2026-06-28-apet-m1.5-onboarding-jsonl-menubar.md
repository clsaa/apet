# apet M1.5 实现计划 v2：开箱即用 + 常规 App 体验

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **v2 已整合第二轮 5 视角面板对计划的评审**（架构 3 运行期 blocker / 测试字节算术与 transition 核对 / AI 真实字段路径 / 产品体验落地）。见 spec §13。

**Goal:** 让 apet 不装 hook 也能看到所有 Claude Code 会话（含当前在跑的，且首屏即绿点），并提供常规 macOS App 的菜单/引导体验。

**Architecture:** jsonl 只读扫描源用**内容信号**派生 raw 状态（scanner 纯函数），watcher 做滞回 + 差分、经**进程内 `SessionSource.jsonl` 标记**合成事件、走**唯一的 `NDJSONIngestor`（共享 seq 源）**融进 `SessionStore`；**jsonl 一律 replay=false、不接通知器（永不发 OS 通知）、不碰 hook 会话生命周期**。菜单栏补右键 NSMenu + 左键面板齿轮；引导精简 + hook/通知授权 just-in-time。

**Tech Stack:** Swift 5.9 / SwiftPM 三 target（AgentPetCore 纯逻辑、AppShellKit 可测胶水、apet GUI）、XCTest、Foundation only。

## Global Constraints

权威设计：`docs/superpowers/specs/2026-06-28-apet-onboarding-jsonl-menubar-design.md`（**§13 修订 supersede 冲突处**）。verbatim：

- **零外部依赖**——仅 Foundation。**不用 `Date()`/`Date.now`**——`now: Double`（Unix 秒墙钟，与 fs mtime 同域）注入。
- **唯一 seq 源**：jsonl 合成事件**必须经同一个 `NDJSONIngestor.ingest(event:)` 取号**，不得自带计数器。去重键 `eventId`；归一键 `(agent, root, sessionId)` 含 `root`。
- **`SessionSource {hook, jsonl}`**：进程内标记，加到内存 `AgentEvent`（默认 `.hook`，**不进 wire `decode`**）与 `Session`，经 `apply` 透传。来源判定/面板柔和渲染/markStale 跳过**一律用 `session.source == .jsonl`**。
- **jsonl 一律 `replay=false`**；**jsonl 路径不接 `NotificationService`**（永不发 OS 通知，零配置=仅面板/桌宠视觉；通知是 hook 专属 just-in-time 增强）。
- **终态 `ended` 不可回退**；`stale` 可复活。字段级合并 last-non-nil-wins；`terminal` 精确值不被空值降级。
- **`markStale` 跳过 `source == .jsonl`**；jsonl 生命周期由 watcher 驱动。
- **滞回在 watcher**（scanner 返回 raw 无 priorState）；running→waitingStop 需连续 2 次 quiet。
- **窗口默认**：`runningWindow=120`、`idleWindow=1800`、`maxBytes=1_048_576`。运算符：running `age < runningWindow`；waitingStop `[runningWindow, idleWindow)`；stale/ignore `age ≥ idleWindow`。
- **watcher 定时回调固定 `queue: .main`**（@MainActor + SessionStore 非线程安全）。
- **测试是规范**——断言精确，覆盖正常/边界/异常。
- 分支 feature；push SSH `git@github.com:clsaa/apet.git`；身份 `clsaa <812022339@qq.com>`；中文 commit。

```swift
    public init(projectsDir: String, root: String, now: @escaping () -> Double,
                scanner: DirectoryScanning = DefaultDirectoryScanner(),

                emit: @escaping (ScanResult) -> Void,
                runningWindow: Double = 120, idleWindow: Double = 1800)
    public func scanOnce()
    public func start(every: Double)   // DispatchSource queue:.main
    public func stop()
}
```
watcher 内部维护 `lastEmitted[key]: ScanState`（差分）+ `quietStreak[key]: Int`（滞回）。每文件 parse→`JSONLSessionScanner.scan`（raw）→ **滞回**：若 raw==.waitingStop 且 lastEmitted==.running → `quietStreak+=1`，<2 则本轮用 `.running`，≥2 用 `.waitingStop` 并清零；其它情况 quietStreak 清零、用 raw。→ 与 lastEmitted 比较，**变化才 emit + 更新 lastEmitted**。`.ignore` 不 emit。

```swift
// start() 内，ingestor 创建后：
let projectsDir = (config.dataRoot as NSString).appendingPathComponent("projects")  // 默认 ~/.claude
let watcher = JSONLDirectoryWatcher(
    projectsDir: projectsDir, root: config.dataRoot,
    now: { Date().timeIntervalSince1970 },
    parse: { JSONLParse.parse(path: $0, root: config.dataRoot) },
    emit: { [weak self] result in self?.applyScanResult(result) })   // 单参，无 replay
self.jsonlWatcher = watcher
watcher.scanOnce()          // seed（replay=false，但 jsonl 不接通知器→天然静默）
watcher.start(every: 8)

private func applyScanResult(_ result: ScanResult) {
    guard let ingestor, let store else { return }
    guard case .observe(let state, let key, let cwd, let title) = result else { return }
    let now = Date().timeIntervalSince1970
    switch state {
    case .running, .waitingStop:
        let kind: EventKind = (state == .running) ? .busy : .stop
        var ev = AgentEvent(v: 1, eventId: "jsonl:\(key.sessionId):\(jsonlSeqCounter)",
                            agent: key.agent, kind: kind, sessionId: key.sessionId,
                            root: key.root, cwd: cwd, title: title, ts: "")
        ev.source = .jsonl; jsonlSeqCounter += 1
        _ = ingestor.ingest(event: ev, now: now, replay: false)   // 不发通知（jsonl 不接 NotificationService）
    case .stale:
        if store.sessions[key]?.source == .jsonl { _ = store.markStaleSession(key, now: now) }
    }
    menuBar?.update(summary: store.summary(), sessions: store.activeSessions())
    petWindow?.update(summary: store.summary(), sessions: store.activeSessions())
}
// jsonlSeqCounter: 进程内 Int，会话内唯一 eventId（替代 UUID，防 seenEventIds 慢泄漏——架构-m2）
```
